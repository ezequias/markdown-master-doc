# Markdown Master Doc

A visual, example-driven reference for writing and formatting Markdown with GitHub Flavored Markdown.

## Guides

| Language | Guide |
| --- | --- |
| English | [Markdown writing and formatting reference](./markdown-reference.md) |
| Portuguese | [Referência de escrita e formatação Markdown](./markdown-reference-pt.md) |

Both guides cover:

- Headings, text styling, quotations, and code
- Colors, links, section anchors, and relative links
- Images, lists, and task lists
- Mentions, issue and pull request references, and emojis
- Paragraphs, footnotes, alerts, and escaping Markdown

## Preview

Open either guide in Visual Studio Code and use **Ctrl+Shift+V** to open the Markdown preview, or **Ctrl+K V** to preview it beside the editor.

The screenshots used by the guides are included in [`assets/images/help/`](./assets/images/help/). Their directory structure matches the image paths in the Markdown, so the existing references work without editing the guide files.
